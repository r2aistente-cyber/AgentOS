# Vision docs

These documents describe where AgentOS is **headed**, not what ships today:

- **[APP.md](APP.md)** — the planned native desktop app (Tauri). The current
  UI is the Vite/React frontend in `frontend/`, shown in a pywebview window.
- **[INSTALL.md](INSTALL.md)** — the planned one-click installer experience.
  Today, AgentOS is installed with `install.sh` / `install.bat` and started
  with `Iniciar-R2Hub.sh` / `.bat` (see the main [README](../../README.md)).
- **[mockup.html](mockup.html)**, **[mockups.html](mockups.html)** — UI mockups.

For the accurate current state, read the top-level README.
